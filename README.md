# ✦ 偉特塔羅・78 張練習占卜器

一個打開瀏覽器就能用的塔羅抽牌網頁，使用 1909 年偉特牌原版圖像。

它不是算命機，比較像一個**陪你練習看牌、把問題想清楚**的小工具：抽牌後先自己看圖、想一想，再對照解讀；想聊得更深，可以一鍵複製結果，貼到你常用的 AI 繼續討論。

👉 **線上使用：** https://mochachen1225-create.github.io/tarot/

---

## 怎麼玩

1. **選一個牌陣**
2. **寫下你的問題**：不知道怎麼問？點開「🤔 不知道怎麼問？」看提示。塔羅比較適合回答「我可以怎麼做」，而不是「會不會」。
3. **按「洗牌並開展牌陣」**：牌會蓋著排好。
4. **一張一張點開牌卡**：正位或逆位是隨機的。點已翻開的牌可以放大看細節。
5. **看解讀**：每張牌都有位置意義、看圖重點、核心解讀和一句鼓勵的話；最後的「把牌串起來看」會把整組牌串成一個故事。
6. **想更深入？** 按「🤖 請 AI 詳解」一鍵複製全部內容，貼到 ChatGPT、Claude、Gemini 等 AI，就能繼續追問、聊得更深入。

## 功能特色

- **完整 78 張**：22 張大阿爾克那＋56 張小阿爾克那。
- **真隨機洗牌**：使用瀏覽器內建的加密等級亂數（`crypto.getRandomValues`）做 Fisher–Yates 洗牌。
- **翻牌動畫與正逆位**：先看牌背，自己點開；正逆位各 50% 機率，逆位牌會倒著顯示。
- **正逆位牌義**
  - 正位：核心實務解讀＋看圖重點＋「問自己」的提問
  - 逆位：📜 傳統解讀（以偉特《塔羅圖解》為本整理）＋💬 現代白話
  - 每張牌都有一句 🌱 溫柔、往前看的鼓勵
- **學習模式**：「📚 想學塔羅？先自己想三句話」與「看圖重點」預設收合，想練習時再打開，不會先被答案影響。
- **整組牌的小線索**：自動整理大牌比例、主導花色、宮廷牌、王牌、逆位數量等提示。
- **手機友善**：版面自動適應手機；牌面圖片拆成獨立檔案，抽到哪張才下載哪張。

## 檔案結構

```
index.html   網頁本體（樣式、牌義資料、程式都在這裡）
images/      78 張牌面圖片（依牌的 id 命名，例如 major_0.jpg、sea_queen.jpg）
```

純 HTML／CSS／JavaScript，不需要安裝或建置，直接用瀏覽器打開 `index.html` 就能使用。

## 小提醒

塔羅是一面鏡子，不是預言。牌面提供的是看事情的角度，真正的決定，永遠在你自己手上。🌙
